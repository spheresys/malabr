Paged attention is a memory management technique for large language model serving, introduced by vLLM, which stores the key-value cache in fixed-size blocks rather than one contiguous allocation per sequence.

The problem it solves is fragmentation. A naive server reserves a contiguous buffer sized for the maximum sequence length, so a short conversation wastes most of what it reserved, and memory that is free overall cannot be used.

By splitting the cache into blocks, the serving engine can allocate memory on demand as a sequence grows, and blocks belonging to one sequence need not be adjacent in physical memory at all.

Copy-on-write sharing follows naturally. Two sequences that share a prompt prefix can point at the same physical blocks until one of them diverges, which makes parallel sampling and beam search much cheaper than they would otherwise be.

The cost is an indirection: every attention kernel must consult a block table to find where a logical position actually lives, which complicates the kernels and adds a small amount of per-token overhead.

Eviction policy is where the design gets interesting. When the pool is full, the engine must choose which sequence to preempt, and the usual choice is to swap out or recompute the most recently arrived request.

Scheduling interacts with all of this. Continuous batching admits new sequences at token boundaries rather than waiting for a whole batch to finish, so admission decisions and memory decisions cannot be made independently.

In practice the combination raises throughput substantially over static batching, and most production serving stacks have adopted some version of it.
